2️⃣ Explanation in 10-Year-Old Style
Imagine this like a giant Lego hotel game:

DataStore = The toy box that holds all hotels, credit cards, and passwords.

Hotel = A basic hotel Lego — it can tell you its name, if it’s open, and you can book it.

SpaHotel = A special hotel Lego with a spa — same as Hotel, but you can also book a spa day.

Reservation = A ticket saying you booked a hotel.

SpaTicket = A ticket with bubbles — spa is included!

CreditCard = A toy wallet — checks if the card is real.

SecureCreditCard = A wallet with a secret code — checks if you also know the password.

When you run the game:

You pick a hotel.

The system checks if it’s free.

You pay with your card and secret code.

You get a ticket (and spa ticket if you want).
